name: Admin engagement policy
description: Confirmed inactivity rule for admin reports, checks, and manual reminders.
---

Admin reports, inactivity checks, and manual reminders must use the same rule: active client accounts only, measured from the last saved emotion record, or account creation when no emotion history exists.

**Why:** The user explicitly chose this shared definition instead of preserving the conflicting definitions. New clients must receive a full inactivity period before becoming eligible.

**How to apply:** Use full 24-hour days, include the exact cutoff as inactive, and distinguish saved dates from emotion dates. Newly joined clients within their grace period are not evidence of recorded activity. Automatic and therapist-facing reminder systems are separate; do not imply parity without checking them.
